# OBS Auto Framing v0.2.0 Preview

This preview improves identity stability, bounded asynchronous scheduling, recovery, framing, diagnostics, and
Windows installation.

## Tracking and identity

- Improved ByteTrack high- and low-confidence association.
- Low-confidence detections can continue compatible tracks without arbitrarily creating new tracks.
- Added bounded occlusion hold and recently lost-track recovery.
- Improved Subject Lock stability across temporary detection loss.
- Rejected non-finite, negative, and greater-than-one detection confidence values before tracking.

## Scheduling and recovery

- Bounded detector scheduling to one replaceable pending frame.
- Rejected results from stale pipeline generations.
- Added adaptive reacquisition and inference-budget-aware effective detection intervals.
- Kept settings, results, tracker updates, Runtime Statistics, and debug output coherent with the active generation.
- Bounded detector completion accounting so replaced work and failures cannot inflate attempt state.

## Framing

- Improved presenter and group stability.
- Smoothed crop behavior during temporary loss and reacquisition.
- Kept the no-target transition bounded as framing returns to the full source frame.

## Diagnostics

- Expanded Runtime Statistics.
- Reported configured and effective detector intervals.
- Added reacquisition state and counters.
- Added tracker continuation, recovery, and occlusion information.

## Development and packaging

- Added public CI and canonical repository verification.
- Added contributor and support documentation.
- Hardened the public package allowlist.
- Added a public-safe Windows installer with OBS-root validation, OBS-running checks, and hash-based uninstall
  ownership.

## Public model boundary

YOLOX-Tiny remains the default bundled model and ONNX Runtime CPU remains the default backend. YOLOX-Nano, YOLOX-S,
and compatible custom YOLOX models remain optional. This release does not include YOLO26 or pose models.

## Install or upgrade

Close OBS, download `obs-auto-framing-v0.2.0-windows-x64-installer.exe`, and select the OBS root containing
`bin\64bit\obs64.exe`. The installer supports standard, custom, portable, and prepared OBS runtime roots. It can
replace the v0.1.1 public plugin layout without changing OBS scenes, profiles, source settings, or plugin
configuration.

For portable or manual installation, extract `obs-auto-framing-v0.2.0-windows-x64.zip` into the same OBS root.
Manual ZIP installations must also be removed manually.
