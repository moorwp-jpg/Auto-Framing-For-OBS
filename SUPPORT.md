# Support

Start with [installation](docs/install.md) and [troubleshooting](docs/troubleshooting.md). For a bug, include OBS,
Windows, and plugin versions; source/camera type; sanitized logs; selected YOLOX model and tracker; and refreshed
Runtime Statistics. Never post credentials, private URLs, or sensitive filesystem paths.

Use GitHub Issues for reproducible public-preview bugs and feature requests. Security concerns follow
[SECURITY.md](SECURITY.md).
