# Security Policy

## Supported Versions

Only the latest Preview release is supported for security fixes and security-relevant bug reports.

## Reporting A Vulnerability

Do not publish exploit details, secrets, private URLs, credentials, or sensitive log contents in a public issue.
Use GitHub private vulnerability reporting or a draft security advisory when available. If no private channel is
available, open a minimal public issue without sensitive details and request private follow-up from the maintainer.

Please include enough context to reproduce and triage the issue when it is safe to share:

- A short description of the impact.
- Steps to reproduce.
- OBS version.
- Windows version.
- Camera/source type.
- Relevant OBS log snippet with sensitive details removed.
- Plugin runtime status.

Include the plugin version/build label, selected model/backend, and refreshed Runtime Statistics when safe.
